# CameraLink — прототип интерфейса

Первый этап сервиса одноразовых ссылок на страницу камеры.

## Запуск

```powershell
node .\server.mjs
```

Откройте `http://127.0.0.1:4173`.

## Что уже работает

- создание уникальной ссылки через серверный API;
- постоянный журнал, поиск и фильтрация;
- копирование, открытие и отзыв ссылки;
- отдельная адаптивная страница камеры;
- явное согласие пользователя;
- запрос разрешения браузера, обратный отсчёт и снимок;
- автоматическая загрузка фотографии на сервер;
- одноразовость и срок действия ссылки;
- просмотр сохранённого фото в административной панели.

Данные создаются автоматически в `data/db.json`, фотографии — в `data/photos/`. Папка `data` не раздаётся как статические файлы.

Перед публикацией в интернете необходимо добавить авторизацию администратора и развернуть сайт по HTTPS.

## Подключение Telegram

1. Создайте бота у `@BotFather` командой `/newbot` и добавьте его в нужную группу.
2. Скопируйте `.env.example` в `.env` и укажите токен. Не публикуйте файл `.env` и не вставляйте токен в клиентский JavaScript.
3. Отправьте в группе `/start@имя_бота`, затем определите ID группы:

```powershell
node --env-file=.env .\telegram-chat-id.mjs
```

4. Запишите найденный ID в `TELEGRAM_CHAT_ID` и запустите сайт:

```powershell
node --env-file=.env .\server.mjs
```

После загрузки фото сервер автоматически отправит его методом `sendPhoto`. Если Telegram временно недоступен, фотография останется сохранённой на сервере, а в таблице появится отметка об ошибке доставки.

## Авторизация администратора

Добавьте в `.env` уникальный пароль длиной не менее 16 символов и секрет подписи сессий:

```powershell
node .\generate-admin-secret.mjs
```

```dotenv
ADMIN_USERNAME=ваш_логин
ADMIN_PASSWORD=ваш_уникальный_пароль
ADMIN_SESSION_SECRET=результат_команды_выше
```

После изменения `.env` перезапустите сервер с `--env-file=.env`. Административные API, журнал и фотографии доступны только после входа. Страница камеры остаётся доступной по одноразовому токену.

## Развёртывание

Проект не требует сторонних npm-пакетов и запускается на Node.js 20+. Для обычного Node-хостинга используйте:

```powershell
node --env-file=.env server.mjs
```

Для контейнерного хостинга предусмотрен `Dockerfile`. В production обязательны переменные `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET`, `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Не добавляйте `.env` в образ или репозиторий — задавайте секреты в панели хостинга.

Подключите постоянный диск к `/data`, иначе журнал и фотографии пропадут при пересоздании контейнера. Проверка состояния доступна по `GET /healthz`.
